## What Was Created

### 1. Reports Module (Service + List Page)

#### **Report Service** (`services/report.service.ts`)

**Types:**
```typescript
interface Report {
  id: string;
  name: string;
  type: 'attendance' | 'marks' | 'enrollment' | 'faculty-workload' | 'custom';
  description?: string;
  filters?: any;
  status: 'pending' | 'generating' | 'completed' | 'failed';
  fileUrl?: string;
  generatedAt?: string;
  generatedBy?: string;
  createdAt: string;
  updatedAt: string;
  user?: { id: string; firstName: string; lastName: string };
}
```

**6 Hooks:**
- `useReports(filters?)` - List all reports with filtering
- `useReport(id)` - Get single report details
- `useGenerateReport()` - Generate new report
- `useDownloadReport()` - Download report file
- `useDeleteReport()` - Delete report

**Report Types:**
- `attendance` - Attendance reports (daily, weekly, monthly)
- `marks` - Marks reports (assessment-wise, student-wise)
- `enrollment` - Enrollment reports (batch-wise, course-wise)
- `faculty-workload` - Faculty workload reports
- `custom` - Custom report builder

#### **Reports List Page** (`/reports`)

**Features:**
- Data table with 6 columns:
  - Report Name (link to detail)
  - Type (badge)
  - Status (colored badge)
  - Generated At (formatted date)
  - Generated By (user name)
  - Actions dropdown

- Advanced filtering:
  - Search by report name or description
  - Filter by type (attendance, marks, enrollment, faculty-workload, custom)
  - Filter by status (pending, generating, completed, failed)

- Actions dropdown:
  - View Details
  - Download (only for completed reports)
  - Delete

- Generate Report button

**Status Color Mapping:**
```typescript
const statusColors = {
  pending: 'secondary',
  generating: 'default',
  completed: 'outline',
  failed: 'destructive',
} as const;
```

### 3. Notifications Module (Service + Page)

#### **Notification Service** (`services/notification.service.ts`)

**Types:**
```typescript
interface Notification {
  id: string;
  userId: string;
  title: string;
  message: string;
  type: 'info' | 'success' | 'warning' | 'error';
  category: 'attendance' | 'marks' | 'enrollment' | 'system' | 'general';
  isRead: boolean;
  readAt?: string;
  actionUrl?: string;
  metadata?: any;
  createdAt: string;
  updatedAt: string;
}
```

**7 Hooks:**
- `useNotifications(filters?)` - List all notifications
- `useUnreadNotifications()` - Get unread notifications (auto-refetch every 30s)
- `useMarkNotificationRead()` - Mark single notification as read
- `useMarkAllNotificationsRead()` - Mark all notifications as read
- `useCreateNotification()` - Create notification
- `useBulkNotification()` - Send notification to multiple users
- `useDeleteNotification()` - Delete notification

#### **Notifications Page** (`/notifications`)

**Features:**
- **Filter Tabs:**
  - All Notifications
  - Unread (with count badge)

- **Notification Cards:**
  - Category icon (emoji)
  - Title with type badge
  - "New" badge for unread
  - Timestamp
  - Message
  - Action URL link (if available)
  - Mark as read button
  - Delete button

- **Mark All as Read button** (when unread count > 0)

- **Empty state** with bell icon

## Usage Examples

### Generating a Report
```typescript
const { mutate: generateReport } = useGenerateReport();

generateReport({
  name: 'Attendance Report - August 2024',
  type: 'attendance',
  description: 'Monthly attendance for all courses',
  filters: {
    startDate: '2024-08-01',
    endDate: '2024-08-31',
    batchId: 'batch-id',
  },
  format: 'pdf',
});
```

### Downloading a Report
```typescript
const { mutate: downloadReport } = useDownloadReport();

downloadReport('report-id');
// Automatically downloads the file
```

### Getting Dashboard Stats
```typescript
const { data: stats } = useDashboardStats();

console.log(`Total Students: ${stats.totalStudents}`);
console.log(`Average Attendance: ${stats.averageAttendance}%`);
```

### Sending Notifications
```typescript
const { mutate: sendNotification } = useCreateNotification();

sendNotification({
  userId: 'user-id',
  title: 'Attendance Alert',
  message: 'Your attendance is below 75%',
  type: 'warning',
  category: 'attendance',
  actionUrl: '/academic/attendance',
});
```

### Bulk Notifications
```typescript
const { mutate: bulkNotify } = useBulkNotification();

bulkNotify({
  userIds: ['user-1', 'user-2', 'user-3'],
  title: 'Marks Published',
  message: 'Midterm marks have been published',
  type: 'info',
  category: 'marks',
  actionUrl: '/academic/marks',
});
```

### Marking Notifications as Read
```typescript
const { mutate: markRead } = useMarkNotificationRead();
const { mutate: markAllRead } = useMarkAllNotificationsRead();

// Mark single notification
markRead('notification-id');

// Mark all notifications
markAllRead();
```

### Querying Audit Logs
```typescript
const { data: logs } = useAuditLogs({
  action: 'CREATE',
  entity: 'Student',
  startDate: '2024-08-01',
  endDate: '2024-08-31',
});

logs.forEach(log => {
  console.log(`${log.user?.firstName} ${log.action} ${log.entity}`);
});
```

### Exporting Audit Logs
```typescript
const exportLogs = useExportAuditLogs();

await exportLogs({
  action: 'DELETE',
  entity: 'Student',
  startDate: '2024-01-01',
});
// Automatically downloads Excel file
```
